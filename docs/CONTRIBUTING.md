# Участие в разработке ZaStoGram Desktop

Ошибки, предложения и обсуждения принимаются в разделе Issues репозитория:

<https://git.zapret.moe/zapretdiscordyoutube/ZaStoGram_desktop/issues>

Обычная открытая регистрация даёт право создавать задачи и комментарии, но не
даёт право отправлять код. Если для исправления нужен доступ к ветке или Pull
Request, администратор проекта выдаёт его явно после обсуждения задачи.

## Требования к изменению

- одна задача должна решать одну понятную проблему;
- нельзя смешивать функциональную правку с массовым форматированием;
- перед отправкой нужно выполнить проверки из
  `Telegram/SourceFiles/tests/release_guards.txt`;
- Windows-изменения дополнительно проверяются локальной Release-сборкой;
- сообщение коммита должно объяснять не только что изменено, но и зачем;
- секреты, ключи подписи, журналы и готовые локальные конфигурации в Git не
  добавляются.

Основная рабочая ветка форка — `dev`. Канонический адрес репозитория:

```text
ssh://git@git.zapret.moe:2222/zapretdiscordyoutube/ZaStoGram_desktop.git
```

Синхронизацию с исходным Telegram Desktop выполняют сопровождающие проекта
отдельными проверяемыми обновлениями. Пользовательские изменения не должны
самостоятельно подменять этот процесс.

Инструкции по подготовке среды находятся в каталоге [`docs`](.).
